# Player character + sled

An original, realistic adult (mid-30s man, average build, ~1.79 m) with a summer and a winter
outfit on one game-engine skeleton, 11 animation clips, and a generic moulded-plastic sled.
Everything is generated by scripts in `character/` from CC0 MakeHuman data.

| output | what |
|---|---|
| `web/assets/character.glb` | skinned character, both outfits, all clips (meshopt + WebP) |
| `web/assets/sled.glb` | sled + ropes + `SledSeat` attachment empty |
| `character/character_hires.blend` | Cycles version: subdivision, live procedural shaders, SSS skin, real hair curves, NLA clips, sled |
| `renders/character_*.png` | 1280x720 Cycles check renders (`render_checks.py`) |

## Rebuild

```bash
cd character
./fetch_assets.sh                                  # CC0 MakeHuman data -> _mh_cache/ (not in git)
/home/user/venv/bin/python build_character.py      # -> character_hires.blend   (~10 s)
NODE_MODULES=<dir containing three, @gltf-transform/*, meshoptimizer, sharp> ./run_web.sh
                                                   # bake 1024 atlases, export, compress (~6 min)
/home/user/venv/bin/python render_checks.py        # Cycles checks (--only, --samples, --res)
NODE_PATH=<node_modules with three@0.170.0> node tools/webtest/test.cjs ../web/assets <outdir>
                                                   # headless Chromium (SwiftShader) load + clip test
```

Modules: `mh_base.py` (hm08 loader, macro/detail targets, mhclo fitting, joints), `char_body.py`
(recipe, body, eyes, armature, weights), `garments.py` (clothes + shoes), `hair.py` (strands, cap,
brows, lashes, atlas), `materials.py` (procedural shaders + masks), `anim.py` (FK/IK solver + baker),
`clips.py` (the clips), `sled.py`, `export_web.py`, `render_checks.py`, `tools/`.

## Character

* Base: hm08 body (13.4 k quads, subdivision-ready). Macro recipe in `char_body.RECIPE/DETAILS`.
* Skeleton: MakeHuman **game_engine** (53 bones, Unreal-like names: `Root, pelvis, spine_01..03,
  neck_01, head, clavicle_*, upperarm_*, lowerarm_*, hand_*, 15 finger bones/hand, thigh_*, calf_*,
  foot_*, ball_*`). MakeHuman weights, limited to 4 influences and normalised; garments get weights
  by nearest-face interpolation from the body (loose tops have reduced upper-arm influence on the
  torso panels); shoes/boots are rigid on foot/ball (+calf for the boot shaft); eyes, lashes, brows,
  hair are rigid on `head`.
* Rest pose: MakeHuman A-pose. Ground at z=0 is the bottom of the shoe soles (bare foot 2.6 cm up).
  Facing glTF +Z (Blender -Y).
* Body is split for the web by visibility so hidden skin is not rendered and cannot poke through:
  `Body_Head` (head, neck, collar band — both outfits) and `Body_Arms` (lower upper-arm to hands —
  summer only). The hi-res `.blend` uses a Mask modifier (`vis_summer` / `vis_winter`).

### Outfits (separate meshes, one GLB)

| outfit | meshes (node names) | material |
|---|---|---|
| summer | `Summer_Tshirt`, `Summer_Jeans`, `Summer_Sneaker_l/_r`, `Hair_Cap_Summer`, `Body_Arms` | `Outfit_Summer` (1024 atlas) |
| winter | `Winter_Jacket` (puffer), `Winter_Pants` (snow pants), `Winter_Gloves`, `Winter_Beanie`, `Winter_Boot_l/_r`, `Hair_Cap_Winter` | `Outfit_Winter` (1024 atlas) |
| shared | `Body_Head`, `Eyes`, `Lashes`, `Brows` | `Skin`, `Eyes`, `Hair` |

Show one set, hide the other (`visible=false`) — 4 materials per outfit (Skin, Eyes, Hair, Outfit).
Garments are shells of the body surface: Taubin-smoothed (no anatomy through cloth), eased out,
drape envelopes (tee/jacket hang straight from the chest; straight-leg jeans; baggy snow pants),
quilted baffles, procedural folds, straightened hems with inward-turned bands. Shoes/boots are
lofted parametric shells with separate soles and toe spring. Fabric detail (jersey knit, denim
twill + slub + fades + tan topstitching along seams, ripstop + zipper, rib knit, leather, tread)
comes from procedural shaders, live in the `.blend` and baked (albedo / normal incl. hi-res folds /
roughness) into the 1024 atlases for the web.

### Skin, eyes, hair

* Skin: procedural (mottling, freckles, regional redness — cheeks/nose/ears/knuckles, lips, stubble
  shadow, under-eye tone, pores + fine wrinkles bump, oilier T-zone/lips roughness). Cycles uses
  random-walk SSS; the web bake ships albedo + normal + roughness, and the glTF material carries
  `KHR_materials_sheen/ior/specular` so `GLTFLoader` builds a `MeshPhysicalMaterial`.
* Eyes: MakeHuman high-poly eyes (cornea alpha -> `BLEND`, clearcoat).
* Hair: short crop. Cycles: 70 k real hair curves (Principled Hair, melanin) + brow strands,
  bone-parented to `head`. Web: a hair-cap shell + brow cards + lash strips (MakeHuman lash
  helpers) sharing one 1024 RGBA atlas that is rasterised from the same strands; material `Hair`
  is `alphaMode MASK` (cutoff 0.4), double-sided. In winter only a fringe below the beanie remains.

## Animation clips (30 fps, in place, Root stays at the origin)

| clip | s | loop | notes |
|---|---|---|---|
| `idle` | 4.0 | yes | breathing (spine/clavicles/neck), slow weight shift with planted feet, head drift |
| `walk` | 1.067 | yes | **1.30 m/s**; IK foot plant with heel-strike / ball roll, pelvis bob/sway/yaw/list, counter-rotating thorax, arm swing |
| `run` | 0.733 | yes | **3.2 m/s**; flight phase, high heel recovery, 11° lean, bent-arm drive |
| `jump` | 1.4 | no | anticipation crouch, arm swing, take-off at 0.42 s, ~0.33 m ballistic, landing absorb at 0.92-1.05 s |
| `sled_sit` | 2.0 | yes | seated, heels against the curl, both hands on the side handles, breathing sway |
| `sled_lean_left` / `sled_lean_right` | 1.0 | yes | full poses: hips shift + torso lean into the turn, head counter-tilt (crossfade with `sled_sit` by steering amount) |
| `sled_air` | 1.0 | yes | airborne tuck: knees up, chest down, hands on handles |
| `superman` | 1.6 | no | push-out 0-0.35 s, body flies horizontal off the back of the sled holding the handles, return 1.15-1.6 s |
| `spread_eagle` | 1.4 | no | "star": off the seat, legs straight and spread, arms up/out, back to sit by 1.4 s |
| `sled_grab` | 1.6 | no | right hand grabs the sled side, left hand waves overhead (one-hand wave) |

Walk/run move the feet backwards at the listed speed — move the character at that speed and they
stay planted (scale `timeScale` = speed / clip speed for other speeds). Trick clips start and end
in the `sled_sit` pose so they can be triggered from it and crossfaded back.

## Sled (`sled.glb`)

Generic modern HDPE toboggan, 1.2 m x 0.51 m, rolled rim, curled front, two handle slots per side,
pull rope + side grab ropes; blue scuffed plastic (baked 512 maps). Front = glTF -Z (Blender -Y,
same as the character). Node `Sled` (mesh), children `SledRope_*` and the empty **`SledSeat`**
(0, 0.02, -0.18 in glTF; on the seat behind the centre). For sled clips parent the character root
to `SledSeat` with an identity transform: `sledGltf.scene.getObjectByName('SledSeat').add(character)`.
Hands meet the handle slots and heels the floor in that space.

## Three.js usage

```js
import { MeshoptDecoder } from 'three/addons/libs/meshopt_decoder.module.js';
const loader = new GLTFLoader().setMeshoptDecoder(MeshoptDecoder);       // EXT_meshopt_compression
const gltf = await loader.loadAsync('assets/character.glb');            // textures are WebP
const setOutfit = (o) => gltf.scene.traverse(m => { if (!m.isMesh) return;
  const s = /^(Summer_|Hair_Cap_Summer|Body_Arms)/.test(m.name), w = /^(Winter_|Hair_Cap_Winter)/.test(m.name);
  m.visible = o === 'summer' ? !w : !s; m.castShadow = true; });
const mixer = new THREE.AnimationMixer(gltf.scene);
const act = n => mixer.clipAction(THREE.AnimationClip.findByName(gltf.animations, n));
```
Skinned meshes: set `frustumCulled = false` (or enlarge bounds) for the sled tricks.

## Known issues / next steps

* Procedural garments are sculpted shells, not simulated cloth: folds are generic, the tee is a
  little boxy and sleeves stand slightly off the arm in the A-pose.
* Extreme poses (arms overhead in the puffer) still stretch the jacket side panels a little.
* Web hair is a shell + alpha (no per-strand silhouette); the Cycles version uses real curves.
* No facial rig/blend shapes (MakeHuman expression units were not ported); the mouth stays closed.
* The hm08 eyelid/eye fit is MakeHuman's; eyes do not track a target.
