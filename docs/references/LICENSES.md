# Licences and attribution — Higashiyama (Yasaka) 3D reconstruction

This file records the third-party sources used by the reference/evidence workstream
(`docs/references/`, `docs/evidence/`) and how each is credited.

## Use of photographs (read this first)

* Wikimedia Commons photographs were used **only as human visual reference**. A reviewer looked
  at each thumbnail to describe materials, colours, façade layout and proportions in words and numbers.
* **No photogrammetry, texture extraction, image tracing or other asset extraction was done.** No image pixels
  are used in any model, texture or render. The few colour hex values in the evidence files are rounded
  median samples of small patches, used as starting points for hand-picked material colours. Pixel ratios
  for the pagoda were measured by hand on thumbnails, and the resulting numbers are labelled `estimated_from_photo`.
* No image files are stored in this repository. Thumbnails (960 px) were downloaded for viewing to a temporary
  scratch directory outside the repo.
* All files listed in `commons_geotagged.json` carry a reusable licence: CC0, CC BY 2.0/2.5/3.0, or
  CC BY-SA 2.0/3.0/4.0. No NC or ND licences were found. If a photo is ever shown or redistributed (it is not
  at present), credit it as: *"<title>" by <author>, <licence>, via Wikimedia Commons (<source page URL>)*.
  CC BY-SA files also need share-alike for any adapted image.

  These terms are compatible with CC BY 4.0.
* Required credit: 「出典：国土地理院」 or "Source: Geospatial Information Authority of Japan (GSI)", naming the
  dataset (for example 地理院タイル（シームレス空中写真）, 基盤地図情報数値標高モデル). Edited data must be marked as edited.
* Survey-Act (測量法) approval may be needed for some survey-grade derivatives. This workstream produced none.

## PLATEAU (国土交通省 Project PLATEAU, City of Kyoto 3D city model)

* CityGML (`data/raw/plateau`, mesh 52353692: bldg, tran, dem) is used under the **PLATEAU利用規約 / G空間情報センター
  terms**, which are compatible with CC BY 4.0 (https://www.mlit.go.jp/plateau/site-policy/ ; dataset page on
  https://www.geospatial.jp/).
* Required credit, for example: 「出典：国土交通省 Project PLATEAU（京都市 3D都市モデル）」 /
  "Source: MLIT Project PLATEAU, Kyoto City 3D city model". Edited data must be marked as edited.
* Used here for `measuredHeight`, `storeysAboveGround`, `yearOfConstruction`, structure type, LOD2 roof geometry
  analysis (eave height, pitch, ridge orientation) and the pagoda's roof outline and apex.
* The PLATEAU LOD2 texture images (`*_appearance/*.jpg`) were not used by this workstream.
